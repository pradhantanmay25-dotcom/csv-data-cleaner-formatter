# CSV Data Cleaner & Formatter 🧹

A sleek, responsive, and mobile-friendly frontend utility application built to solve messy corporate spreadsheet problems. It processes text data locally in the browser with speed and security.

## ✨ Features
- **Automated Trim Filter:** Instantly strips out messy, uneven spaces inside individual data cells.
- **Deduplication Engine:** Automatically scans rows to find and remove identical duplicate records.
- **Row Optimizer:** Completely deletes empty or blank rows to ensure a continuous dataset.
- **Mobile-Optimized UX:** Built with a premium, responsive dark-themed card interface perfect for smartphone displays.
- **Utility Actions:** Features an instant "Copy to Clipboard" trigger and dynamic client-side `.csv` file download handling.

## 🛠️ How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser on your phone or laptop—no server setup required!
